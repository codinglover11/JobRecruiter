# Job Scraper — Frontend

React + Vite + Tailwind + Zustand client for the Job Scraper portal. Lets a
logged-in user trigger the Naukri or LinkedIn Apify scrapers, watch results
land with a timestamp, and export them as CSV.

## Setup

```bash
npm install
cp .env.example .env   # point VITE_API_BASE_URL at your backend
npm run dev             # http://localhost:5173
```

Login with one of the two seeded accounts created on the backend.
